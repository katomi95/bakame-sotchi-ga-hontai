# 馬鹿め。そっちが本体だ

**▶ 遊ぶ: https://katomi95.github.io/bakame-sotchi-ga-hontai/**

分身の術の最中、あっさり本体を斬られた忍者。
倒れた本体を背に、分身が言い放つ。「馬鹿め。そっちが本体だ」
――格好はついたが、状況は最悪。本体の命が尽きる前に、残った分身三体で刺客を討て。

PCブラウザ向けの見下ろし型2Dアクション（1プレイ1〜3分）。冒頭の場面はクリック／Spaceで飛ばせます。

## 操作

| キー | 動作 |
|---|---|
| WASD / 矢印 | 移動 |
| マウス | 攻撃の向き |
| 左クリック | 刀 |
| 右クリック | 手裏剣（分身ごとに3枚・補充なし） |
| Space | 次の分身へ切り替え |
| 1〜3 | 分身を直接選ぶ |
| Esc | 一時停止・操作説明 |
| R | やり直す |
| M | 音のオン／オフ |

## ルール

- 本体の命は時間で減る（90秒）。ゼロになると本体が死に、分身も全員消える。
- 分身は一撃で煙になる。操作していない分身も斬られる。補充・復活なし。
- 刺客は近い分身を狙う。切り替えても狙いは変わらない。
- 突進斬り・薙ぎ払いのあとの「隙」に斬れば大きく効く。囮で引きつけ、別の分身で斬れ。

## 開発メモ

- 素のHTML / Canvas / JavaScript。外部素材・外部APIなし（効果音はWebAudioで合成）。
- 調整値は `js/config.js` にまとめてある（制限時間・敵体力・攻撃速度・手裏剣数など）。
- `node tools/test.js` でルールの自動確認と、ボット同士の対戦によるバランス確認ができる。
